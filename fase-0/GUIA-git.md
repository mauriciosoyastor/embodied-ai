# GUIA — git y GitHub (Fase 0, mini-hito 3, parte 1)

Objetivo: versionar tu código y publicarlo en GitHub. El orden recomendado es Python → git → Linux → Docker, así que esto va después de Python.

## Qué aprender (mínimo viable)

1. **Qué es git**: una "máquina del tiempo" para tu código. Guarda versiones y podés volver atrás.
2. **Comandos básicos**:
   - `git init` — crear un repositorio.
   - `git add .` — marcar archivos para guardar.
   - `git commit -m "mensaje"` — guardar la versión.
   - `git status` — ver qué cambió.
   - `git log` — ver el historial.
3. **Qué es GitHub**: una nube donde vive una copia de tu repositorio.
   - `git remote add origin <url>` — conectar tu repo local al de GitHub.
   - `git push` — subir tus commits.
   - `git pull` — bajar cambios.
