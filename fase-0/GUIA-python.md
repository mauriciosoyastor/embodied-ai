# GUIA — Python (Fase 0, mini-hito 1)

Objetivo: escribir un script Python que corra. Conceptos mínimos, en orden, con recursos externos gratis.

## Qué aprender (mínimo viable)

1. **Variables y tipos**: números, texto (strings), booleanos.
2. **Funciones**: `def`, parámetros, `return`.
3. **Condicionales**: `if` / `elif` / `else`.
4. **Bucles**: `for` y `while`.
5. **Listas y diccionarios**: colecciones básicas.
6. **Leer archivos**: `open()`, `with`.
7. **Ejecutar un script**: `python mi_script.py` y el bloque `if __name__ == "__main__":`.

## El ejemplo de este repo

- `contar_palabras.py` — la función pública `contar_palabras(texto)` (con tests).
- `main.py` — el script ejecutable que lee un archivo y usa la función.
- `test_contar_palabras.py` — tests con pytest (los escribimos antes que el código, TDD).

Probá modificarlo: cambiá la función, corré los tests, mirá qué pasa.

## Recursos externos gratis

- FreeCodeCamp: "Scientific Computing with Python" (cursos en español disponibles).
- Python.org: tutorial oficial (en inglés).
- SoloZombies / aprenderpython.org: práctica en español.
